How to create your token (one time):
  1. Go to GitHub → Fine-grained tokens
  2. Repository access: Only select repositories → this website's repo
  3. Permissions: Contents → Read and write. Nothing else.
  4. Generate, copy, and paste it above.
The token stays in your browser only — it is never stored in the website code.
